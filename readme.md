# 📚 คอร์สแวร์ วิทยาการคำนวณ ว21101 (โรงเรียนบ้านแมดนาท่ม)

ระบบคอมพิวเตอร์ช่วยสอน (CAI) สำหรับรายวิชาวิทยาการคำนวณ (ว21101) ระดับชั้นมัธยมศึกษาปีที่ 1 ออกแบบมาเพื่อรองรับนักเรียนจำนวน 60 คน พร้อมระบบจัดการหลังบ้านสำหรับครูผู้สอน โดยทำงานผ่านเว็บแอปพลิเคชัน (Single-Page Application) และใช้ **Supabase** เป็นระบบฐานข้อมูลและยืนยันตัวตน

## ✨ ฟีเจอร์หลัก (Features)

*   **ระบบผู้ใช้งาน 2 ระดับ (Role-based Access):**
    *   **👨‍🎓 นักเรียน (Student):** เข้าเรียนบทเรียน, ดูวิดีโอ, ส่งงาน/แบบฝึกหัด, ติดตามความก้าวหน้า (Progress) ของตนเอง และแก้ไขโปรไฟล์
    *   **👨‍🏫 ครูผู้สอน (Teacher):** ดูภาพรวมของนักเรียนทั้งหมด (60 คน), ตรวจสอบความก้าวหน้า, ดูจำนวนงานที่รอตรวจ
*   **โหมดจำลอง (Mock Mode):** สามารถทดสอบการทำงานของ UI ได้ทันทีโดยไม่ต้องเชื่อมต่อฐานข้อมูลจริง (มีระบบจำลองข้อมูลนักเรียนและบทเรียนในตัว)
*   **การออกแบบที่ตอบสนอง (Responsive Design):** ใช้งานได้ดีทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน
*   **ระบบฐานข้อมูลแบบ Real-time (ผ่าน Supabase):** รองรับการเก็บข้อมูลผู้ใช้, บทเรียน, การส่งงาน และคะแนน

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

*   **Frontend:** HTML5, JavaScript (Vanilla), Tailwind CSS (ผ่าน CDN)
*   **Icons:** Lucide Icons
*   **Backend & Database:** Supabase (PostgreSQL, Auth, Storage)

## 🚀 ขั้นตอนการติดตั้งและตั้งค่าระบบ (Setup Instructions)

หากต้องการเปลี่ยนจากโหมดจำลอง (Mock Mode) เป็นการใช้งานจริงกับฐานข้อมูล ให้ทำตามขั้นตอนดังนี้:

### 1. การตั้งค่า Supabase
1. สมัครสมาชิกและสร้างโปรเจกต์ใหม่ที่ [Supabase](https://supabase.com/)
2. ไปที่เมนู **SQL Editor**
3. คัดลอกคำสั่ง SQL ทั้งหมดจากไฟล์ `schema.sql` (ที่ให้ไว้ในชุดโค้ด) ไปวางและรัน เพื่อสร้างตาราง `profiles`, `lessons`, `assignments`, และ `submissions` พร้อมตั้งค่าความปลอดภัย (RLS)
4. ไปที่เมนู **Storage** และสร้าง Buckets 2 อัน (ตั้งเป็น Public) คือ:
    *   `avatars` (สำหรับเก็บรูปโปรไฟล์)
    *   `assignments` (สำหรับเก็บไฟล์งานที่นักเรียนแนบมา)

### 2. การเชื่อมต่อ Frontend กับ Supabase
1. เปิดไฟล์ `cai_app.html` ด้วยโปรแกรมแก้ไขโค้ด (เช่น VS Code)
2. ค้นหาส่วนของ `<script>` บรรทัดที่ประมาณ 225
3. แก้ไขตัวแปร `SUPABASE_URL` และ `SUPABASE_ANON_KEY` ให้ตรงกับข้อมูลโปรเจกต์ของคุณ (หาได้จาก Supabase -> Project Settings -> API)

```javascript
// เปลี่ยนข้อมูลตรงนี้เป็นของจริง
const SUPABASE_URL = 'https://your-project-id.supabase.co'; 
const SUPABASE_ANON_KEY = 'your-anon-key-here';
```

*หมายเหตุ: เมื่อใส่ Key ของจริง ระบบจะออกจาก Mock Mode และพยายามเชื่อมต่อกับฐานข้อมูลจริงโดยอัตโนมัติ*

### 3. การนำไปใช้งาน (Deployment)
เนื่องจากระบบฝั่งหน้าบ้านเป็นเพียงไฟล์ HTML คุณสามารถนำไฟล์ `cai_app.html` ไปฝากไว้ที่โฮสติ้งฟรีต่างๆ ได้ทันที เช่น:
*   GitHub Pages
*   Vercel
*   Netlify

## 📝 โครงสร้างฐานข้อมูลเบื้องต้น

*   **profiles:** เชื่อมกับระบบ Auth เก็บข้อมูลส่วนตัว เช่น ชื่อ, รหัสนักเรียน, บทบาท
*   **lessons:** เก็บบทเรียน, เนื้อหา, วิดีโอลิงก์
*   **assignments:** เก็บโจทย์และแบบฝึกหัดที่ผูกกับบทเรียน
*   **submissions:** เก็บข้อมูลการส่งงานของนักเรียน, ไฟล์ที่แนบ, และคะแนนที่ได้
